Current Route Map

Squat

Dedicated pose is still the correct control and the strongest measured solution.

Run: squat_tcn_l1_channels96 MAE: 2.14 Within-1: 0.5625 CI added in Stage 11
Pull-up

Still mixed. Shared pose keeps the best practical Within-1 tradeoff even after dedicated follow-up tuning.

Run: pose_count_tcn_pull_up_seq192 MAE: 4.61 Within-1: 0.4286 Dedicated pose improved MAE only
Push-up

RGB remains the strongest practical branch. Pose-only and transformer variants did not change that conclusion.

Run: rgb_count_tcn_push_up_seq128 MAE: 6.60 Within-1: 0.2778 Routed branch for Stage 8

Stage Flow

1. Understand the data EDA plots, class balance, temporal annotations, inspection PDFs.
2. Prepare and extract Clean labels, build indexes, extract pose and RGB features.
3. Compare architectures Shared pose, dedicated pose, RGB, transformer, multimodal, routed.
4. Review failures Audit hard cases, inspect video intervals, confirm real challenges.
